### 🚀 پروژه‌های شاخص

#### 🛡️ [RTLume — افزونه راست‌چین برای هوش مصنوعی](https://github.com/hosseinahmadi-expert/rtlume-firefox-extension)
یک افزونه سبک و کاملاً آفلاین برای فایرفاکس که جهت متن (راست‌چین/چپ‌چین) را در سایت‌های هوش مصنوعی (مثل ChatGPT، Claude و DeepSeek) به صورت خودکار اصلاح می‌کند.
- **تکنولوژی‌ها:** JavaScript, CSS, Manifest V3
- **ویژگی‌ها:** پشتیبانی از Shadow DOM، فونت محلی وزیرمتن، حریم خصوصی مطلق.
- **وضعیت:** منتشر شده در [فروشگاه افزونه‌های Mozilla](https://addons.mozilla.org).

*(به زودی پروژه‌های مربوط به تم‌های وردپرس و ابزارهای سی‌شارپ نیز اینجا اضافه می‌شوند...)*
